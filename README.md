# Caja Fácil — descargas

Instaladores de **Caja Fácil**, la caja para kioscos y almacenes. El código es privado.

Descargá la última versión desde **[Releases](../../releases/latest)**: `CajaFacil_x.y.z_x64-setup.exe` (Windows 10/11, 64 bits).

Si Windows muestra "Windows protegió su PC": **Más información → Ejecutar de todas formas**.

La app se actualiza sola cuando sale una versión nueva.
